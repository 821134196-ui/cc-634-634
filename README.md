# 签证材料原件托管与领回系统

旅行社收取护照等签证原件后，客户可凭收件凭证查询**每一件材料**当前在哪里；
使馆**分批退件**时只更新被退回的件，缺件保持"外部办理中"，**整单不能提前完结**。
客户（或代领人）按件签收，交接全程双方留痕、记录只追加。

## 一条命令启动

```bash
./run.sh              # 首次会自动建虚拟环境、装依赖、初始化演示数据
# 可选：./run.sh --reset        清空数据重来
# 可选：./run.sh --port=9000
```

启动后打开 <http://127.0.0.1:8000>

技术栈：Python 3.11 + FastAPI + SQLAlchemy 2 + SQLite；Vue 3（本地 vendor，无需 Node 构建、运行时不联外网）；
证件照片与使馆回执均为本地文件；短信为落库模拟。

## 演示账号

| 账号 | 口令 | 岗位 | 用途 |
|---|---|---|---|
| `admin` | `admin123` | 管理员 | 全部功能与照片 |
| `reception` | `recep123` | 前台收件岗 | 收件、经手件照片 |
| `handler` | `handle123` | 经办岗 | 递交/退件/领回（演示订单经手人） |
| `handler2` | `handle123` | 经办岗 | **未经手演示订单**，验证跨客户拦截 |
| `viewer` | `view123` | 只读统计岗 | 看列表，**无权看证件照片** |

演示订单含 4 件原件、1 个有效代领授权（王代领）与 1 个已过期授权（孙过期）。

## 业务规则对照

- **逐件编号拍照**：收件时每件原件独立编号（`订单号-序号`）、拍照本地存档，出具客户收件凭证（链接在订单详情页，可复制，公开视图不含证件影像）。
- **逐件状态机**：在库保管 → 递交后"外部办理中" → 使馆退件后"待领回" → 客户按件签收"已领回"。
- **部分退件不覆盖整单**：使馆只退部分件时，其余件仍标"使馆/签证中心（外部办理中）"；
  只有全部单件均已签收，`completed_at` 才写入。不存在"整单标记完成"接口。
- **交接只追加**：收件 / 递交（生成模拟使馆回执文件）/ 退件 / 领回均按批次追加流水；
  分批送达、改自取只新增记录，最初收件单与历史不可修改，系统无任何 PUT/PATCH/DELETE 交接接口。
- **代领校验**：授权限本人（姓名+证件号双匹配）、限有效期、可撤销、可限定材料范围；
  过期、撤销、人证不符、超范围一律 403。
- **证件照片访问控制**：只有经手岗位（收件/经办/管理员）且**实际经手该订单**才能打开照片，
  每次允许或拒绝都写 `photo_access_logs` 审计；只读岗与其他客户的经手人 403；存储层另有路径穿越防护。
- **模拟短信**：收件、退件、部分领回、全部完结自动写入 `sms_outbox`（"短信记录"页可查）。

## 目录结构

```
backend/        FastAPI 应用（models / main / services / security / seed）
frontend/       Vue 3 单页应用（含本地 vendor/vue.global.prod.js）
tests/          20 项验证测试
data/           运行时生成：app.db、photos/（证件照片按客户隔离）、receipts/（使馆回执）
run.sh          一条命令启动
```

## 运行验证测试

```bash
.venv/bin/python -m pytest tests/ -q
```

覆盖的三类关键安全/业务断言：

1. **缺件不被整单归还覆盖**（`tests/test_partial_return.py`）
   - 3 件全递交 → 仅退 2 件 → 第 3 件保持 `submitted`、订单未完；
   - 领回 2 件后缺件数 1、仍未完；尚在使馆的件不能被签收；
   - 最后一件退回并签收后，订单才完结。
2. **代领须有有效授权**（`tests/test_proxy_auth.py`）
   - 无授权 / 过期 / 已撤销 / 姓名不符 / 证件号不符 / 超范围 / 跨订单使用授权全部 403；
   - 有效授权成功且流水标明代领签收。
3. **证件资料隔离**（`tests/test_photo_access.py`）
   - 只读岗 403；未经手的经办/收件岗跨客户 403；经手后 200；管理员 200；
   - 无令牌 401；拒绝访问有审计；公开凭证不泄露照片字段；路径穿越被存储层拦截。
4. 另有 `tests/test_append_only.py` 验证流水只追加、无修改/删除/整单完成接口。
